# LastScene과 전체 게임 흐름 복구

## 목표

원본 결과 Scene과 Title부터 결과·재시작까지 전체 게임 루프를 복원한다.

## 상세 작업 단위

### A. LastScene 근거와 자산 확정
### B. 결과 Scene 구현
### C. 전체 Scene 루프와 저장 상태 복원

## 진행률

잔여 작업 3개 (A, B, C)

## 변경 금지

- 임의 물고기명, 등급, 중량 또는 결과 화면을 만들지 않는다.

## 인수 기준과 테스트

- 대표 Stage가 Title부터 LastScene과 재시작/복귀까지 PlayMode/GPU 검증을 통과한다.
