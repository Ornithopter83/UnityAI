# TestModule UI 반영 현황

Updated: 2026-09-11

## 이번 반영

- 본체 LED 위치를 `0: 꺼짐`, `1: 중앙`, `2: 왼쪽(비활성)`, `3: 오른쪽(비활성)`으로 교정했다.
- 위치 2와 3을 선택하면 적용 버튼이 비활성화되도록 했다.
- LED 색상 인터페이스에 누락됐던 `00: White`, `15: Black`을 추가했다.
- LED, 릴/IMU, 입력/전원, LM JIG, 업데이트 탭의 실행 버튼을 모터 제어와 같은 flat 색상 버튼으로 통일했다.
- ON/OFF 선택도 flat 버튼 형태로 통일했다.
- 원본 인터페이스 기준으로 릴 왼쪽/오른쪽/SETUP/BOOT 버튼의 상태 색상을 교정했다.
- README에만 있고 실제 화면에는 없던 `입력 / 전원` 탭을 추가했다.
- `$27`의 BOOT, 엔코더 A/B, BLDC FG, USB 5V, 전원 스위치 상태가 실제 UI에 표시되도록 했다.
- `$12` 배터리와 `$14` ROD 엔코더 상태 표시를 추가했다.
- 본체 엔코더 `$27 03-03`과 ROD 엔코더 `$14`를 서로 다른 표시값으로 분리했다.
- 본체 엔코더 UI는 `회전값 수신`이 ON인 경우에만 방향과 카운트를 갱신한다.

## 아직 미반영 또는 확인 필요

- 릴 버튼의 더블 클릭/길게 누름 코드(`12`, `16`, `22`, `26`)는 기존 펌웨어에서 미사용으로 기록돼 있어 별도 UI를 추가하지 않았다.
- LM JIG의 HOME/LEFT/RIGHT 센서 도달 결과는 현재 AP 응답 계약이 확정되지 않아 완료 상태 UI로 표시하지 않았다.
- LED 위치 2/3은 사용자 확인대로 비활성 처리했으나, 실제 하드웨어에서 해당 출력이 존재하는지는 장비 검증하지 않았다.
- 배터리와 ROD 엔코더 payload의 단위·부호 표기는 원문 그대로 표시한다. 표시 단위 변환 규칙은 별도 사양이 필요하다.
- 버튼 색상, 탭 배치와 새 입력 상태 영역의 실제 화면 렌더링은 아직 확인하지 않았다.
