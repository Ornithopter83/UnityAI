# 레벨 선택과 게임 진입 복구

## 목표

SelectScene의 SINGLE 확정 이후 원본 레벨/맵 선택과 Gameplay 로드를 복원한다.

## 상세 작업 단위

### A. 원본 상태·UI 근거 확정
- State_SelectCharacter/Level/Map과 관련 Scene 자산을 조사한다.

### B. 선택 UI와 데이터 연결 복원
- 확인된 순서, 좌표, 입력, StageData 계약만 구현한다.

### C. Loading과 Stage 진입 검증
- 선택 결과가 올바른 로드 대상으로 이어지는지 검증한다.

## 진행률

잔여 작업 3개 (A, B, C)

## 변경 금지

- 근거 없는 선택 UI를 만들거나 BATTLE 서버 동작을 섞지 않는다.

## 인수 기준과 테스트

- SINGLE 이후 원본 범위의 선택과 첫 Stage 진입이 PlayMode/GPU 검증을 통과한다.
