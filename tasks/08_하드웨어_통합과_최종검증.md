# 하드웨어 통합과 최종 검증

## 목표

PC simulator와 실제 장비 경계를 검증하고 전체 프로젝트의 빌드·회귀·전달을 완료한다.

## 상세 작업 단위

### A. `DF_Integration` 계약 대조 및 필요 시 `DF_FW_Code` 소스 확인
### B. 승인된 실제 장비 단계 검증
### C. 전체 회귀와 Player 빌드 검증
### D. 문서와 전달 정리

## 진행률

잔여 작업 4개 (A, B, C, D)

## 변경 금지

- 실제 장비, 결제, OS 종료, 모터 구동을 자동 또는 무승인으로 실행하지 않는다.

## 인수 기준과 테스트

- 전체 게임과 대상 빌드가 검증되고 남은 제한이 명시된다.
