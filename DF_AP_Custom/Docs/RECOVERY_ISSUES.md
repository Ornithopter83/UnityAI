# Recovery Issues

Updated: 2026-09-10

원본 복구에 필요한 Scene, 3D Object, Material, Texture, Shader, Prefab, Animator, Audio, 코드 또는 시각 근거를 찾지 못했거나 근거가 충돌할 때 기록하는 문제 목록이다.

## 기록 규칙

- 원본 추출물에서 실제로 검색한 뒤에만 `누락`으로 판정한다.
- 검색 전 항목은 `미조사`, 이름이나 GUID가 불명확한 항목은 `식별 불가`로 구분한다.
- 비슷한 자산을 임의로 대체하지 않는다.
- 각 문제는 관련 Scene, 기대 항목, 검색 범위와 방식, 발견 결과, 영향, 필요한 추가 근거, 사용자 결정 여부를 포함한다.
- 해결 시 삭제하지 않고 해결 날짜와 채택 근거를 남긴다.

## 상태 정의

- `미조사`: 원본 추출물 검색 전
- `누락`: 정해진 검색 범위를 확인했지만 원본 항목을 찾지 못함
- `식별 불가`: 후보는 있으나 Scene/GUID/시각 근거로 확정할 수 없음
- `근거 충돌`: 구조·자산·스크린샷·동영상 또는 사용자 확인이 서로 다름
- `사용자 확인 대기`: 복구 방향에 명시적 결정이 필요함
- `해결`: 채택 근거와 검증 결과가 확정됨

## 문제 목록

### RI-001 — AP 버전 요청 프레임과 통합 프로토콜 충돌

- 상태: `근거 충돌`
- 관련 Scene/상태: Serial 연결 초기화 및 버전 조회
- 기대 항목: `DF_Integration/PROTOCOL.md`와 Unity Serial 구현의 동일한 요청 프레임
- 검색 범위와 방식: `DF_Integration/PROTOCOL.md`, `UnityProject/Assets/Scripts/Hardware/Serial/SerialProtocol.cs`, `Docs/HARDWARE_PROTOCOL.md` 정적 비교
- 발견 결과: 통합 기준은 `$10%`이지만 현재 Unity 코드와 기존 AP 기술 문서는 `$10-%`를 사용한다.
- 영향: 실제 MAIN 펌웨어에서 버전 조회가 실패하거나 배포 버전별 호환 동작이 달라질 수 있다.
- 필요한 추가 근거: Integration 기준 펌웨어/TestModule 실기 또는 loopback 검증. 필요 시 읽기 전용 `DF_FW_Code` parser 확인
- 사용자 결정: Integration 문서를 우선 계약으로 지정함. 코드 수정은 별도 통합 작업에서 검증 후 수행
- 해결 기록: 미해결
