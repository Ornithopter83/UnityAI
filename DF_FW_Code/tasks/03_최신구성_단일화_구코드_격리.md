# 작업 03

최신 구성 단일화와 구 코드 격리

## 목표

현재 사용하는 Main/Rod 구성만 활성 코드에 남기고 과거/비활성 분기는 빌드 외부 `deprecated/`에 보존한다.

## 현재 기준

- Main `Config.h`와 Rod `Common.h`에 다수의 Variant, test flag, `#if 0` 및 과거 주석 코드가 존재한다.
- 사용자는 과거 Variant로 돌아갈 계획이 없다.

## 관련 영역

- Main `Config.h`, `Common.h`, `DF_Main.ino`
- Rod `Common.h`, `DF_Rod.ino`
- 향후 `deprecated/main/`, `deprecated/rod/`

## 구현 원칙

- 먼저 deprecated 파일을 만든 뒤 활성 코드에서 제거한다.
- deprecated는 sketch 폴더 밖에 두며 빌드하지 않는다.
- C++11 이후 문법과 namespace를 사용하지 않는다.
- `#pragma once`, C++03 `enum`, `const`, `extern`을 사용한다.

## 세부 작업

### A. deprecated 보존 규약과 색인 (완료: 2026-08-27)

- 경로, 파일 머리말, 출처 및 대체 코드 기록 형식을 만든다.

### B. Main 현재 설정 고정 (완료: 2026-08-27)

- 작업 01에서 확정된 활성 분기를 별도 목록으로 만들고 한 기능군씩 단일화한다.

### C. Main 구 코드 격리와 전처리 제거 (완료: 2026-08-27)

- 과거 interface, motor/hardware, test 및 disabled block을 기능별 deprecated 파일로 옮긴다.

### D. Rod 현재 설정 고정 (완료: 2026-08-27)

- 최신 보드/입력/배터리/Encoder/IMU 구성을 단일 값으로 만든다.

### E. Rod 구 코드 격리와 전처리 제거 (완료: 2026-08-27)

- 과거 보드와 비활성 기능을 deprecated로 옮기고 잘못된 조건 이름을 별도 결함으로 기록한다.

### F. C++03 호환 상수와 헤더 정리 (완료: 2026-08-27)

- include guard는 `#pragma once`, 헤더 전역 정의는 `.cpp` 단일 정의로 정리한다.

### H. 수동 빌드와 smoke 게이트 (미수행: 2026-08-27, 사용자 지시)

- Main과 Rod 각각 단일화 직후 Codex가 build를 실행한다.
- 주요 입출력과 통신 smoke test가 끝나기 전 다음 대규모 작업으로 넘어가지 않는다.

### I. BLDC PWM 반전 및 16W 설정 원본 복구 (완료: 2026-08-31)

- 현재 코드는 PWM 반전 계산, 초기화·정지 PWM 1023 및 16W 설정을 적용한다. 시험 배율 제거와 명령/PWM 단위 주석·UART 로그 보완도 유지한다.
- 사용자가 최신 코드가 옳다고 확인하여 해결 완료 처리했다. 추가 분석을 중지하고 이 건의 미해결 기록 및 후속 요청을 제거했다.
- 완료 근거: 사용자 확인 및 종료 지시. Codex는 이번 건의 신규 빌드·테스트·장비 검증·업로드를 실행하지 않았다.
- 원본과 수정 전 소스 보존본은 유지하며 활성 펌웨어 코드는 이번 종료 처리에서 변경하지 않았다.

## 진행

잔여 구현 작업 0개. 작업 03-I 해결 완료(사용자 확인). 이 건과 무관한 기존 통합 검증은 해당 작업서에서 별도로 관리한다.

## 변경 금지

- 활성 branch를 재설계하거나 프로토콜 값을 변경하지 않는다.
- deprecated 코드를 현재 코드에서 참조하지 않는다.

## 완료 조건

- 활성 코드에는 현재 제품 경로만 존재하고 제거된 코드는 출처와 함께 deprecated에 보존되어 있다. 구조 변경은 완료했으며 동작 검증은 수행하지 않았다.

## 시험 방법

- 각 기능군 제거 후 compile gate, Main/Rod 단일화 완료 후 사용자 수동 smoke test.

- 2026-08-27 작업 03-B~E 완료: 전체 기준 원본을 `legacy/Vm1.0.9.0`, `legacy/Vr1.0.1.0`으로 이동하고 활성 복사본을 `firmware/DF_Main`, `firmware/DF_Rod`에 구성했다. 활성 파일의 단순 현재 분기를 선택하고 `#if/#ifdef/#else/#endif` 제품 분기를 제거했다. Rod는 New Board V2, Button V2, Break 없음, Encoder V3, Battery 800 V2 경로로 고정했다.

- 2026-08-27 불필요 Rod staging 도구를 `deprecated/tools/stage-rod.cmd`로 이동하고 build script가 `firmware/DF_Rod`를 직접 사용하도록 변경했다.
