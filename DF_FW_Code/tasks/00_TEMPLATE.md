## 구현 원칙

- C++98/03 문법, 고유 접두어, namespace 미사용.
- 제거 코드는 활성 코드 밖 `deprecated/`에 보존.
- compile/link 빌드는 Codex가 실행한다. 플래시/장비 검증이 필요하면 중단하고 사용자에게 알린다.
