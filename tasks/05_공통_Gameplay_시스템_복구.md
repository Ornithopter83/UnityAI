# 공통 Gameplay 시스템 복구

## 목표

Busan에서 검증한 3D·상태·UI·데이터·입력 기반을 모든 Stage가 재사용할 수 있게 한다.

## 상세 작업 단위

### A. 공통 Scene/Prefab 경계 확정
### B. 물고기·낚싯대·장력·카메라 복원
### C. Audio/VFX/환경 시스템 복원
### D. 회귀 검증 기반 구축

## 진행률

잔여 작업 4개 (A, B, C, D)

## 변경 금지

- 복구와 무관한 대규모 리팩터링이나 패키지 업그레이드를 하지 않는다.

## 인수 기준과 테스트

- 새 Stage가 공통 기반을 재사용하고 Busan EditMode/PlayMode 회귀가 통과한다.
